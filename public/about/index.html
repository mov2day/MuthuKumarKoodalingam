Profile · Quality Engineering

Muthu Kumar Koodalingam

I work on quality engineering systems that make release decisions easier to trust: test automation architecture, API and mobile testing, CI/CD quality gates, observability, developer tooling and practical AI-assisted testing.

My work focuses on turning testing from a collection of scripts into an engineering feedback system. That means choosing the right test layer for the risk, making failures explainable, keeping automation maintainable, and building tools that teams can actually own.

Areas of work

Test automation architecture

Component, API, integration and end-to-end strategies designed around risk, feedback speed and maintainability.

API testing

Karate DSL, OpenAPI-driven workflows, coverage analysis, negative testing, contract thinking and reusable test design.

Mobile quality engineering

Android component testing, selective device validation and focused end-to-end coverage instead of oversized UI suites.

AI-assisted testing

Agent workflows, deterministic guardrails, evidence-based generation and using AI where it improves engineering judgment.

CI/CD and observability

Quality gates, failure triage, actionable reporting and release evidence that reduces the distance from red build to resolution.

Developer tooling

Open-source plugins, extensions and analysis tools that bring quality feedback closer to engineers.
